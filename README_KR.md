# Event ON — 업데이트된 프로젝트

## 반영된 내용
- 앱을 열었을 때 첫 화면이 업로드한 시안의 구성으로 표시되도록 랜딩 화면을 교체했습니다.
- 첫 번째 시안의 행사 기획 사진을 메인 히어로 배경으로 적용했습니다.
- 두 번째 시안에서 4개 기능 카드 이미지를 추출해 `public/images/`에 저장하고, 기능 소개 영역을 구현했습니다.
- `설계 시작하기`는 행사 설계 워크스페이스로 이동합니다.
- `행사 정보 입력`, `3D 공간 배치`, `운영 분석`, `보고서 작성` 카드는 기존 워크스페이스·분석·보고서 화면으로 연결됩니다.
- 작은 화면에서는 기능 카드가 1열 또는 2열로 재배치되도록 반응형 스타일을 추가했습니다.
- 기존 프로젝트에 없던 `server.ts`를 실행하던 스크립트를 Vite 실행 명령으로 수정했습니다.

## 실행 방법
프로젝트 폴더에서 다음 명령을 순서대로 실행하세요.

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음과 같습니다.

```bash
npm run build
```

## 주요 수정 파일
- `src/components/LandingPageView.tsx`
- `src/index.css`
- `public/images/` (홈 화면 이미지 5개)
- `index.html` (브라우저 제목 및 설명)
- `package.json` (실행 스크립트)
- `metadata.json`
